# Hanqunfeng Color_echo

## How do I install these formulae?

`brew install hanqunfeng/color_echo/<formula>`

Or `brew tap hanqunfeng/color_echo` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "hanqunfeng/color_echo"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
